# Contributing to PyManager

Open an issue with the steps to reproduce the problem, what you expected, your operating system, and the relevant Python version or installation source. Replace usernames and machine-specific paths in logs or screenshots before sharing them.

For a pull request, follow the [local setup](README.md#run-locally). Describe what changed, which platforms you checked, and how you verified it. If a change installs or removes interpreters, use disposable environments for testing.
